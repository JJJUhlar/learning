# Active Learning Tools

Skills for avoiding brain rot through active learning.

Each skill pushes you towards 'desirable difficulty' in learning, instead of Claude just giving you the answer. 

- **Quiz:** expose gaps in your current understanding
- **Socratic:** teaches through guided questioning, instead of just explanation
- **Demo:** creates an interactive widget explore a concept
- **Traffic Light:** map out competence in different areas of a topic 
- **Case Studies:** use worked examples to gain understanding
- **Questions:** work out what you should be asking next
